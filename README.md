# Hanzel Events

A React + Tailwind landing page staged as **the invitation suite** — hero as a
stationery card, process as a ceremony programme, portfolio as place-cards.
The wax seal (H&E) is the recurring mark.

## Run

```bash
npm install
npm run dev
```

## Palette

Ink `#171215` · Ivory `#F7F0E4` · Oxblood `#7C1F2E` · Brass `#B4915A` · Blush `#EFE1D6`

## Extending

- `PROGRAMME`, `WEDDINGS`, `TESTIMONIALS`, and `SERVICES` live as arrays in `src/App.tsx`.
- Wire `handleSubmit` in `Enquire` to Formspree, a serverless function, or a CRM when you are ready for real enquiries.
- Real photography slots most naturally behind the invitation card, and as thumbnails on the place-cards.
